🎯 Funkciók:

  • Folyamatos jobbról-balra csúszás mobil nézetben
  • Hover-re megáll az animáció
  • Végtelen loop (seamless)
  • Gradient fade-out a széleken
  • Grayscale → színes hover effekt
  • GPU gyorsított, smooth animáció

Partner Ikonok

🖱️ Használat:

  • Desktop (>768px): Normál flex layout, középre igazítva
  • Mobile (≤768px): Automatikus carousel animáció
  • Hover: Mozgasd az egeret az ikonra → animáció megáll
  • Scroll: Az animáció folytatódik, amikor elveszed az egeret

⚙️ Testreszabás:

  • Animáció sebessége: partner-carousel.css → animation-duration
  • Breakpoint: partner-carousel.js → CONFIG.breakpoint
  • Ikon távolság: .carousel-track .partner-icon { margin: 0 2rem; }
  • Gradient szélesség: .partnerek-sor::before { width: 100px; }
